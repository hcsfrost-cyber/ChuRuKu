📄 Excel / CSV 批量导入（旧电子台账，可多文件）

支持 .xlsx / .xls / .csv，一次可选多个文件，也可直接拖进下方区域，或分多次「追加」。
· 表头需含：日期、经办人（可选）、名称、型号规格（可选）、数量、单位（可选）、单价 / 总价——列顺序不限、名称可近似匹配；无需「经费性质」列，导入时可统一指定；
· 相同「日期 + 经办人」的行自动合并为一张单据；同一张单内完全相同的明细行自动去重（如三联模板同一耗材打印了三份，只保留一条）；无表头则按「日期/名称/型号规格/数量/单位/单价/总价」列顺序解析；
· 与台账中已有单据完全相同的会标记「疑似重复」，默认自动跳过，避免手滑重复导入；
· 默认存入「存档导入」组（可改），与网页录入的单据区分开，之后可随时互移分组。
📁 点击选择文件（可多选），或将 Excel / CSV 拖到这里
例如：2023台账.xlsx、2024台账.xlsx、2025上半年.csv …… 一批全选即可

同步机制（配置好后全自动）：保存 / 删除 / 恢复 / 彻底删除 / 导入 / 移动分组时只把改动的单据即时上传（增量，不会用旧数据覆盖云端）； 打开页面、从后台切回、切换到台账 / 回收站 / 仪表盘时自动与云端双向对齐；分组清单本身也会同步。 正在填写的表单不会被同步打断；同一张单以最后修改时间为准。
在 Supabase SQL Editor 中执行：
create table if not exists records (
  id text primary key,
  payload jsonb,
  updated_at timestamptz default now());
alter table records enable row level security;
create policy "all" on records for all using (true) with check (true);
